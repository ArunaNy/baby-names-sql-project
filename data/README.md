- The data was taken from the U.S. Social Security Administration's official website
(https://catalog.data.gov/dataset/baby-names-from-social-security-card-applications-national-data).
- The dataset included 146 files in .txt format and included baby name registrations in the U.S. from 1880 to 2025. I joined these files into one CSV file using Python's pandas for later analysis.
- The resulting joined dataset is too heavy to be uploaded to GitHub (37 MB, max is 25 MB). However, the Python file I uploaded ("data_transformation_exploration.ipynb") allows viewing the data.
